1.1.1 Input/Output and Basic Data Types

Now this printf function can be very powerful. Like Java, we can pass values into placeholders like %d, %f, %s, %c, namely double, float, string, and character. Here is an example.

Code 1.1.2: 26clcwy-02

1#include <stdio.h> 
2 
3int main() { 
4    int age = 123; 
5    double gpa = 3.14; 
6    char name[] = "Enoch"; 
7 
8    printf("%s is %d years old.\n", name, age); 
9    printf("He has a GPA of %f and a letter grade of %c\n", gpa, ’A’); 
10    printf("%s also loves math. For example...\n", name); 
11    printf("%f / %d = %f\n", 1.0, 5, 1.0 / 5); 
12 
13    return 0; 
14}

As you can see, we can define integer, double, float, and character as usual. We can also pass our values into the place holder. You may have noticed that we wrote char name[] = "Enoch"; instead of string name = "Enoch";. This is because unlike other languages, C doesn’t have data type string in its usual sense. We will discuss more about this as we discuss arrays and pointers. Finally, notice that we wrote \(1.0\) instead of \(1\) for our first %f in the last line. This is because \(1\) by itself is an integer and we will get an error. Compiling and running, we get the following output.

Output 1.1.3

Enoch is 123 years old. 
He has a GPA of 3.140000 and a letter grade of A 
Enoch also loves math. For example... 
1.000000 / 5 = 0.200000

As you can see, we get \(3.140000\) instead of \(3.14\). When displaying, C likes to give a more accurate value. Continuing, we have same commenting style as C++.

Now as mentioned previously, strings are quite different in C. They are not totally different data types, but just an array of characters. This simple nature of C is one of the factors that makes C special, but also slightly annoying.

Now before moving onto inputs and outputs, here is one more data type. This one called struct is quite interesting because it is user-defined and also a composite data type. It can look like a class without functions, but they are different. Struct defines data type that we can use to organize information. Here is an example usage.

Code 1.1.8: 26clcwy-05

1#include <stdio.h> 
2 
3typedef struct { 
4    float a; 
5    float b; 
6    float c; 
7} array ; 
8 
9struct vector { 
10    float x; 
11    float y; 
12}; 
13 
14int main() { 
15    // Using vec 
16    struct vector vec; 
17    vec.x = 0.1; 
18    vec.y = 0.2; 
19    printf("v   = <%f, %f>\n", vec.x, vec.y); 
20 
21    // Using arr 
22    array arr = { .a = 0.1, .b = 0.2, .c = 0.3, }; 
23    printf("arr = [%f, %f, %f]\n", arr.a, arr.b, arr.c); 
24 
25    return 0; 
26}

Output 1.1.9

v   = <0.100000, 0.200000> 
arr = [0.100000, 0.200000, 0.300000]

Struct is nice because we can use it like a template and reuse it multiple times. Also we will discuss more on typedef later but we can use it as shown above to avoid writing more characters. When we want our main function to be on the very top, then we need something called prototype. Function prototypes and declaration are used interchangeably with slight difference in nuance. As shown below, we need to basically tell the compiler that the function that we will be using in the main function exists, so that it doesn’t complain about it.
